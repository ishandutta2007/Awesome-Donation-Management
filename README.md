# Awesome-Donation-Management

Top Donation Management EcosystemCurated List of SaaS Products & Open-Source GitHub ProjectsFocused on Online Giving, Donor CRM & Nonprofit Fundraising OperationsLast updated: September 2026This repository tracks notable SaaS platforms and open-source projects for Donation Management. These tools help nonprofits, churches, and charitable organizations accept online donations, manage donor relationships, process recurring gifts, and generate giving statements.Examples include Givebutter, Donorbox, GiveWP, Qgiv, Network for Good, Classy, Fundraise Up, Funraise, Zeffy, OneCause, Tithe.ly, Pushpay, Givelify, Kindrid, EasyTithe, Vanco Give, Subsplash Giving, Planning Center Giving, and SecureGive (the category leaders).Open-source emphasis: This section is expanded with active projects for self-hosting, custom giving workflows, and transparent donor data management — ideal for churches, nonprofits, and developers building vendor-independent donation platforms. The open-source ecosystem is anchored by CiviCRM (comprehensive nonprofit CRM), ChurchCRM (church management), and GiveWP (WordPress donation plugin), with strong coverage in church-specific treasury systems and crowdfunding platforms.Contributions welcome!
